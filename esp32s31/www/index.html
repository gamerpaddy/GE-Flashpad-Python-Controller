    Processing chain (order)
    

      
    
        
  1. Dark subtraction – int32 subtract, clamp 0…65535, nothing added back. Skipped without a dark, for dark frames, or on a size mismatch.
    2. 
        
  2. Line repair – dead rows / columns (robust running-median detector, border 12) from the dark-subtracted frame OR the dark; manual rows / columns join the list; linear interpolation, truncated to u16.
    3. 
        
  3. Pixel repair – manual pixels, then optional automatic hot / dead pixels (median of good neighbours). Runs after the lines on purpose.
    4. 
        
  4. Destripe → Background flatten → Denoise → Unsharp → Local contrast – float32, each one bypassable. Rounded to u16 afterwards.
    5. 
        
  5. Rotate / flip – the result is the processed 16-bit data that the RAW-processed and PNG-16 saves contain.
    6. 
        
  6. Window (percentile or manual, optional gamma / log / sigmoid curve) → 8 bit.
    7. 
        
  7. CLAHE on the 8-bit window (cv2-exact) → Invert → Palette = displayed image and PNG display.
